# 📚 MongoDB Fundamentals Assignment

This assignment is designed to help you build foundational skills in **MongoDB**, covering setup, CRUD operations, advanced queries, aggregation pipelines, and indexing.  

---

## 📖 Assignment Overview  
- ✅ Set up a MongoDB database (locally or on Atlas)  
- ✅ Perform basic **CRUD** (Create, Read, Update, Delete) operations  
- ✅ Write **advanced queries** with filtering, projection, and sorting  
- ✅ Create **aggregation pipelines** for data analysis  
- ✅ Implement **indexing** for performance optimization  

---

## 🚀 Getting Started

1. **Accept the Assignment**  
   - Accept the GitHub Classroom invitation sent to you.  
   - Clone your personal repository that was generated by GitHub Classroom:  
     ```bash
     git clone https://github.com/PLP-MERN-Stack-Development/week-1-mongodb-fundamentals-assignment-marycathline.git
     cd week-1-mongodb-fundamentals-assignment
     ```

2. **Set Up MongoDB**  
   - Install MongoDB locally **OR** create a free [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) account.  
   - Ensure you have **Node.js (v18 or higher)** installed.  
   - Ensure you have **MongoDB Shell (mongosh)** or **MongoDB Compass** for database interaction.  

3. **Populate the Database**  
   - Run the provided script to insert sample book data:  
     ```bash
     node insert_books.js
     ```
   - This will populate your MongoDB collection with sample data for testing queries.
